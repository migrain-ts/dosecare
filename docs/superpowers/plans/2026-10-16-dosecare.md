# DoseCare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build DoseCare, a medication tracking and reminder platform (API + worker + web) that runs locally with `docker compose up`.

**Architecture:** npm-workspaces monorepo. `packages/db` (Drizzle schema, migrations, test DB helper), `packages/shared` (Zod schemas, `Clock`), `apps/api` (Hono), `apps/worker` (idempotent reminder cycle over a Postgres outbox), `apps/web` (Next.js + Ant Design + Tailwind v4). All integration tests run against a real PostgreSQL.

**Tech Stack:** TypeScript, Node 22+, Hono, Drizzle ORM + drizzle-kit, `pg`, Zod, `@node-rs/argon2`, luxon, nodemailer, Vitest, Next.js App Router, Ant Design + `@ant-design/nextjs-registry`, Tailwind v4, Playwright, Docker Compose, Mailpit.

**Spec:** `docs/superpowers/specs/2026-10-16-dosecare-design.md`

## Global Constraints

- Everything free, no hosted demo, fictional data only, no medical advice anywhere in the UI.
- UI and README in English only.
- Versions pinned exactly (`npm i -E`) once installed; record them in the commit.
- Authorization: one `requireRole(min)` middleware is the only authorization point; a non-member gets **404**, never 403.
- Every worker step is idempotent; the outbox `dedupe_key` is unique; delivery is at-least-once (documented).
- Time is always read from an injected `Clock` (never `new Date()` inside services or the worker).
- Schedules are entered in the recipient's local time and stored/compared in UTC.
- Session tokens, invitation tokens: random 32 bytes, only their SHA-256 hash is stored.
- Hono runs middleware in registration order. A router mounted at `/` that starts with `.use('*', requireAuth)` protects every route registered after it. `GET /openapi.json` and `GET /docs` must therefore be registered before those routers and stay public (the coverage test in Task 5 lists them as public; Task 9 asserts they answer 200 without a session).
- Host ports on the developer machine: Postgres 5440, Mailpit SMTP 1026 and UI 8026, API 4000, web 3001 (5432, 1025, 8025 and 3000 are taken by other projects). Inside the Docker network the services keep their default ports.
- Docs for libraries are checked with the context7 MCP when an API detail is uncertain (Hono, Drizzle, Ant Design, Next.js).

## Review Focus

1. **DST gap and overlap**: a dose at 02:30 local on the spring-forward day (nonexistent) and the fall-back day (repeated) must produce exactly one dose each. Pinned in Task 10.
2. **Double take race**: two concurrent `POST /doses/:id/take` must record one dose and one stock decrement; the second gets 409. Pinned in Task 8.
3. **Concurrent workers**: two dispatchers running together must send each outbox row exactly once, and a crashed claim must be reclaimed. Pinned in Task 12.
4. **Dead credentials**: expired, revoked and unknown session tokens return 401; an invitation is single use, expirable, and cannot be accepted twice. Pinned in Tasks 4 and 6.
5. **Unbounded ranges**: `GET /recipients/:id/doses` rejects ranges over 31 days with 400 instead of scanning the table. Pinned in Task 8.

`packages/shared/src/clock.ts`:
```ts
export interface Clock {
  now(): Date;
}

export class SystemClock implements Clock {
  now(): Date {
    return new Date();
  }
}

export class FakeClock implements Clock {
  private t: number;
  constructor(start: Date) {
    this.t = start.getTime();
  }
  now(): Date {
    return new Date(this.t);
  }
  advanceMs(ms: number): void {
    this.t += ms;
  }
  advanceMinutes(m: number): void {
    this.t += m * 60_000;
  }
  set(d: Date): void {
    this.t = d.getTime();
  }
}
```

```ts
  boolean, date, index, integer, jsonb, numeric, pgEnum, pgTable, primaryKey, text, time,
  timestamp, unique, uuid,
} from 'drizzle-orm/pg-core';

export const memberRole = pgEnum('member_role', ['owner', 'editor', 'viewer']);
export const doseStatus = pgEnum('dose_status', ['pending', 'taken', 'skipped', 'missed']);
export const stockReason = pgEnum('stock_reason', ['refill', 'dose', 'adjustment']);
export const outboxKind = pgEnum('outbox_kind', ['reminder', 'missed_alert', 'low_stock', 'invitation']);
export const outboxStatus = pgEnum('outbox_status', ['pending', 'sending', 'sent', 'failed']);

const ts = (name: string) => timestamp(name, { withTimezone: true });
const qty = (name: string) => numeric(name, { precision: 10, scale: 2, mode: 'number' });

export const users = pgTable('users', {
  id: uuid('id').primaryKey().defaultRandom(),
  email: text('email').notNull().unique(),
  passwordHash: text('password_hash').notNull(),
  name: text('name').notNull(),
  createdAt: ts('created_at').notNull().defaultNow(),
});

export const sessions = pgTable('sessions', {
  id: uuid('id').primaryKey().defaultRandom(),
  userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  tokenHash: text('token_hash').notNull().unique(),
  expiresAt: ts('expires_at').notNull(),
  revokedAt: ts('revoked_at'),
  createdAt: ts('created_at').notNull().defaultNow(),
});

export const recipients = pgTable('recipients', {
  id: uuid('id').primaryKey().defaultRandom(),
  displayName: text('display_name').notNull(),
  timeZone: text('time_zone').notNull(),
  createdAt: ts('created_at').notNull().defaultNow(),
});

export const recipientMembers = pgTable(
  'recipient_members',
  {
    recipientId: uuid('recipient_id').notNull().references(() => recipients.id, { onDelete: 'cascade' }),

    role: memberRole('role').notNull(),
    createdAt: ts('created_at').notNull().defaultNow(),
  },
  (t) => [primaryKey({ columns: [t.recipientId, t.userId] }), index('members_user_idx').on(t.userId)],

export const invitations = pgTable('invitations', {
  id: uuid('id').primaryKey().defaultRandom(),

    id: uuid('id').primaryKey().defaultRandom(),

    strength: text('strength'),
    unit: text('unit').notNull(),
    active: boolean('active').notNull().default(true),
    startDate: date('start_date'),
    endDate: date('end_date'),
    createdAt: ts('created_at').notNull().defaultNow(),
  },
  (t) => [index('medications_recipient_idx').on(t.recipientId)],
);

export const schedules = pgTable('schedules', {
  id: uuid('id').primaryKey().defaultRandom(),
  medicationId: uuid('medication_id').notNull().references(() => medications.id, { onDelete: 'cascade' }),
  daysOfWeek: integer('days_of_week').array().notNull(),
  timeOfDay: time('time_of_day').notNull(),
  quantityPerDose: qty('quantity_per_dose').notNull(),
  startDate: date('start_date').notNull(),
  endDate: date('end_date'),
});

export const stockMovements = pgTable(
  'stock_movements',
  {
    id: uuid('id').primaryKey().defaultRandom(),
```

```ts
import { drizzle, type NodePgDatabase } from 'drizzle-orm/node-postgres';
import { Pool } from 'pg';

export type Db = NodePgDatabase<typeof schema>;

export function createDb(url: string): { db: Db; pool: Pool } {
```

```ts
import { createHash, randomBytes } from 'node:crypto';
import { and, eq, gt, isNull } from 'drizzle-orm';
import { schema, type Db } from '@dosecare/db';

export const SESSION_TTL_MS = 30 * 24 * 60 * 60 * 1000;

export const hashToken = (token: string) => createHash('sha256').update(token).digest('hex');

export async function createSession(db: Db, userId: string, now: Date): Promise<string> {
  const token = randomBytes(32).toString('base64url');
  await db.insert(schema.sessions).values({
    userId,
    tokenHash: hashToken(token),
    expiresAt: new Date(now.getTime() + SESSION_TTL_MS),
  });
  return token;
}

export async function findSession(db: Db, token: string, now: Date) {
  const [row] = await db
    .select({ id: schema.users.id, email: schema.users.email, name: schema.users.name })
    .from(schema.sessions)
    .innerJoin(schema.users, eq(schema.users.id, schema.sessions.userId))
    .where(
      and(
        eq(schema.sessions.tokenHash, hashToken(token)),
        isNull(schema.sessions.revokedAt),
        gt(schema.sessions.expiresAt, now),
      ),
    );
  return row ?? null;
}

export async function revokeSession(db: Db, token: string, now: Date) {
  await db.update(schema.sessions).set({ revokedAt: now }).where(eq(schema.sessions.tokenHash, hashToken(token)));
}
```

```ts
import type { MiddlewareHandler } from 'hono';
import type { Clock } from '@dosecare/shared';
import { ApiError } from './errors';

export function rateLimit(opts: { clock: Clock; windowMs: number; max: number }): MiddlewareHandler {
  const hits = new Map<string, number[]>();
  return async (c, next) => {
    const ip = c.req.header('x-forwarded-for')?.split(',')[0]?.trim() ?? 'local';
    const key = `${c.req.path}:${ip}`;
    const now = opts.clock.now().getTime();
    const recent = (hits.get(key) ?? []).filter((t) => now - t < opts.windowMs);
    if (recent.length >= opts.max) throw new ApiError(429, 'rate_limited', 'Too many attempts, try again later');
    recent.push(now);
    hits.set(key, recent);
    await next();
  };
}
```

```ts
import { getCookie } from 'hono/cookie';
import type { MiddlewareHandler } from 'hono';
import { ApiError } from '../errors';
import type { Env } from '../app';
import { findSession } from './sessions';

export const SESSION_COOKIE = 'sid';

export function tokenFrom(c: Parameters<MiddlewareHandler>[0]): string | undefined {
  const bearer = c.req.header('authorization');
  if (bearer?.startsWith('Bearer ')) return bearer.slice(7);
  return getCookie(c, SESSION_COOKIE);
}

export const requireAuth: MiddlewareHandler<Env> = async (c, next) => {
  const token = tokenFrom(c);
  if (!token) throw new ApiError(401, 'unauthenticated', 'Sign in required');
  const deps = c.get('deps');
  const user = await findSession(deps.db, token, deps.clock.now());
  if (!user) throw new ApiError(401, 'unauthenticated', 'Sign in required');
  c.set('user', user);
  await next();
};
```

```ts
import { zValidator } from '@hono/zod-validator';
import { eq } from 'drizzle-orm';
import { Hono } from 'hono';
import { deleteCookie, setCookie } from 'hono/cookie';
import { schema } from '@dosecare/db';
import { loginSchema, registerSchema } from '@dosecare/shared';
import type { Env } from '../app';
import { ApiError } from '../errors';
import { rateLimit } from '../rate-limit';
import { createRecipient } from '../services/recipients';
import { requireAuth, SESSION_COOKIE, tokenFrom } from './middleware';
import { DUMMY_HASH, hashPassword, verifyPassword } from './password';
import { createSession, revokeSession, SESSION_TTL_MS } from './sessions';

export function authRoutes(deps: import('../app').Deps) {
  const loginLimiter = rateLimit({ clock: deps.clock, windowMs: 15 * 60_000, max: 10 });
  const registerLimiter = rateLimit({ clock: deps.clock, windowMs: 15 * 60_000, max: 50 });

  const issueCookie = (c: Parameters<typeof setCookie>[0], token: string) =>
    setCookie(c, SESSION_COOKIE, token, {
      httpOnly: true,
      sameSite: 'Lax',
      path: '/',
      secure: deps.secureCookies ?? false,
      maxAge: SESSION_TTL_MS / 1000,
    });

  return new Hono<Env>()
    .post('/register', registerLimiter, zValidator('json', registerSchema), async (c) => {
      const body = c.req.valid('json');
      const { db, clock } = c.get('deps');
      const [existing] = await db.select({ id: schema.users.id }).from(schema.users).where(eq(schema.users.email, body.email));
      if (existing) throw new ApiError(409, 'email_taken', 'This email is already registered');
      const [user] = await db
        .insert(schema.users)
        .values({ email: body.email, passwordHash: await hashPassword(body.password), name: body.name })
        .returning();
      const recipient = await createRecipient(db, { ownerId: user!.id, displayName: body.name, timeZone: body.timeZone });
      issueCookie(c, await createSession(db, user!.id, clock.now()));
      return c.json({ user: { id: user!.id, email: user!.email, name: user!.name }, recipient }, 201);
    })
    .post('/login', loginLimiter, zValidator('json', loginSchema), async (c) => {
      const body = c.req.valid('json');
      const { db, clock } = c.get('deps');
      const [user] = await db.select().from(schema.users).where(eq(schema.users.email, body.email));
      const ok = await verifyPassword(user?.passwordHash ?? DUMMY_HASH, body.password).catch(() => false);
      if (!user || !ok) throw new ApiError(401, 'invalid_credentials', 'Invalid email or password');
      issueCookie(c, await createSession(db, user.id, clock.now()));
      return c.json({ user: { id: user.id, email: user.email, name: user.name } });
    })
    .post('/logout', requireAuth, async (c) => {
      const { db, clock } = c.get('deps');
      const token = tokenFrom(c)!;
      await revokeSession(db, token, clock.now());
      deleteCookie(c, SESSION_COOKIE, { path: '/' });
      return c.body(null, 204);
    })
    .get('/me', requireAuth, (c) => c.json({ user: c.get('user') }));
}
```

```ts
import { and, eq } from 'drizzle-orm';
import type { Context, MiddlewareHandler } from 'hono';
import { schema } from '@dosecare/db';
import type { Role } from '@dosecare/shared';
import type { Env } from './app';
import { ApiError } from './errors';

const ORDER: Record<Role, number> = { viewer: 1, editor: 2, owner: 3 };
export const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export type Resolver = (c: Context<Env>) => string | null | Promise<string | null>;

export const fromParam =
  (name = 'id'): Resolver =>
  (c) => c.req.param(name) ?? null;

const viaTable =
  (lookup: (db: import('@dosecare/db').Db, id: string) => Promise<string | undefined>): Resolver =>
  async (c) => {
    const id = c.req.param('id');
    if (!id || !UUID.test(id)) return null;
    return (await lookup(c.get('deps').db, id)) ?? null;
  };

export const fromMedication = viaTable(async (db, id) => {
  const [r] = await db.select({ v: schema.medications.recipientId }).from(schema.medications).where(eq(schema.medications.id, id));
  return r?.v;
});
export const fromDose = viaTable(async (db, id) => {
  const [r] = await db.select({ v: schema.doseEvents.recipientId }).from(schema.doseEvents).where(eq(schema.doseEvents.id, id));
  return r?.v;
});
export const fromSchedule = viaTable(async (db, id) => {
  const [r] = await db
    .select({ v: schema.medications.recipientId })
    .from(schema.schedules)
    .innerJoin(schema.medications, eq(schema.medications.id, schema.schedules.medicationId))
    .where(eq(schema.schedules.id, id));
  return r?.v;
});

export function requireRole(min: Role, resolve: Resolver = fromParam()): MiddlewareHandler<Env> {
  return async (c, next) => {
    const recipientId = await resolve(c);
    if (!recipientId || !UUID.test(recipientId)) throw new ApiError(404, 'not_found', 'Not found');
    const [m] = await c
      .get('deps')
      .db.select({ role: schema.recipientMembers.role })
      .from(schema.recipientMembers)
      .where(and(eq(schema.recipientMembers.recipientId, recipientId), eq(schema.recipientMembers.userId, c.get('user').id)));
    if (!m) throw new ApiError(404, 'not_found', 'Not found');
    if (ORDER[m.role] < ORDER[min]) throw new ApiError(403, 'forbidden', 'Insufficient role');
    c.set('role', m.role);
    c.set('recipientId', recipientId);
    await next();
  };
}
```

```ts
type Tx = Parameters<Parameters<Db['transaction']>[0]>[0];

async function assertNotLastOwner(tx: Tx, recipientId: string, userId: string) {
  const owners = await tx
    .select({ userId: schema.recipientMembers.userId })
    .from(schema.recipientMembers)
    .where(and(eq(schema.recipientMembers.recipientId, recipientId), eq(schema.recipientMembers.role, 'owner')))

}
```

```ts
import { randomBytes } from 'node:crypto';
import { and, eq } from 'drizzle-orm';
import { schema } from '@dosecare/db';
import type { Role } from '@dosecare/shared';
import type { Deps } from '../app';
import { hashToken } from '../auth/sessions';
import { ApiError } from '../errors';
import { addMember } from './recipients';

export const INVITATION_TTL_MS = 7 * 24 * 3600 * 1000;

export async function createInvitation(
  deps: Deps,
  input: { recipientId: string; invitedBy: { id: string; name: string }; email: string; role: Role },
) {
  const now = deps.clock.now();
  return deps.db.transaction(async (tx) => {
    const [recipient] = await tx.select().from(schema.recipients).where(eq(schema.recipients.id, input.recipientId));
    const existing = await tx
      .select({ id: schema.users.id })
      .from(schema.users)
      .innerJoin(schema.recipientMembers, eq(schema.recipientMembers.userId, schema.users.id))
      .where(and(eq(schema.users.email, input.email), eq(schema.recipientMembers.recipientId, input.recipientId)));
    if (existing.length > 0) throw new ApiError(409, 'already_member', 'This person already has access');
    const token = randomBytes(32).toString('base64url');
    const expiresAt = new Date(now.getTime() + INVITATION_TTL_MS);
    const [inv] = await tx
      .insert(schema.invitations)
      .values({ recipientId: input.recipientId, email: input.email, role: input.role, tokenHash: hashToken(token), invitedBy: input.invitedBy.id, expiresAt })
      .returning();
    await tx.insert(schema.notificationOutbox).values({
      kind: 'invitation',
      toEmail: input.email,
      dedupeKey: `invitation:${inv!.id}`,
      nextAttemptAt: now,
      payload: {
        token,
        link: `${deps.appUrl}/invitations/${token}`,
        recipientName: recipient!.displayName,
        inviterName: input.invitedBy.name,
        role: input.role,
      },
    });
    return { id: inv!.id, expiresAt };
  });
}

export async function acceptInvitation(deps: Deps, token: string, userId: string) {
  const now = deps.clock.now();
  return deps.db.transaction(async (tx) => {
    const [inv] = await tx
      .select()
      .from(schema.invitations)
      .where(eq(schema.invitations.tokenHash, hashToken(token)))
      .for('update');
    if (!inv) throw new ApiError(404, 'not_found', 'Invitation not found');
    if (inv.acceptedAt) throw new ApiError(409, 'invitation_used', 'This invitation was already used');
    if (inv.expiresAt <= now) throw new ApiError(409, 'invitation_expired', 'This invitation has expired');
    const [member] = await tx
      .select()
      .from(schema.recipientMembers)
      .where(and(eq(schema.recipientMembers.recipientId, inv.recipientId), eq(schema.recipientMembers.userId, userId)));
    if (member) throw new ApiError(409, 'already_member', 'You already have access');
    await addMember(tx, { recipientId: inv.recipientId, userId, role: inv.role });
    await tx.update(schema.invitations).set({ acceptedAt: now }).where(eq(schema.invitations.id, inv.id));
    return { recipientId: inv.recipientId, role: inv.role };
  });
}
```

```ts
import { sql } from 'drizzle-orm';
import type { Db } from './client';

export type Stock = { tracked: boolean; remaining: number; dailyConsumption: number; daysLeft: number | null };

export async function getStock(db: Db, medicationId: string, today: string): Promise<Stock> {
  const res = await db.execute(sql`
    select
      exists (select 1 from stock_movements where medication_id = ${medicationId} and reason <> 'dose') as tracked,
      coalesce((select sum(quantity) from stock_movements where medication_id = ${medicationId}), 0)::float8 as remaining,
      coalesce((select sum(quantity_per_dose * cardinality(days_of_week) / 7.0) from schedules
                where medication_id = ${medicationId} and (end_date is null or end_date >= ${today}::date)), 0)::float8 as daily
  `);
```

```ts
import { and, asc, eq, gte, inArray, lt, sql } from 'drizzle-orm';
import { Hono } from 'hono';
import { schema } from '@dosecare/db';
import { doseQuerySchema, localDayStartUtc } from '@dosecare/shared';
import type { Env } from '../app';
import { requireAuth } from '../auth/middleware';
import { fromDose, requireRole } from '../authz';
import { ApiError } from '../errors';

const MAX_RANGE_DAYS = 31;

export function doseRoutes() {
  const close = async (c: import('hono').Context<Env>, status: 'taken' | 'skipped') => {
    const { db, clock } = c.get('deps');
    const id = c.req.param('id')!;
    await db.transaction(async (tx) => {
      const [d] = await tx
        .update(schema.doseEvents)
        .set({ status, takenAt: status === 'taken' ? clock.now() : null, recordedBy: c.get('user').id })
        .where(and(eq(schema.doseEvents.id, id), inArray(schema.doseEvents.status, ['pending', 'missed'])))
        .returning();
      if (!d) throw new ApiError(409, 'dose_not_open', 'This dose was already recorded');
      if (status === 'taken') {
        await tx.execute(sql`
          insert into stock_movements (medication_id, quantity, reason)
          select ${d.medicationId}, ${-d.quantity}, 'dose'
          where exists (select 1 from stock_movements where medication_id = ${d.medicationId} and reason <> 'dose')
        `);
      }
    });
    return c.json({ id, status });
  };

  return new Hono<Env>()
    .use('*', requireAuth)
    .get('/recipients/:id/doses', requireRole('viewer'), validator('query', doseQuerySchema), async (c) => {
      const { from, to } = c.req.valid('query');

      const [r] = await db.select({ tz: schema.recipients.timeZone }).from(schema.recipients).where(eq(schema.recipients.id, c.get('recipientId')));
      const start = localDayStartUtc(from, r!.tz);
      const nextDay = new Date(Date.parse(to) + 86_400_000).toISOString().slice(0, 10);
      const end = localDayStartUtc(nextDay, r!.tz);

          medicationId: schema.doseEvents.medicationId,
          medicationName: schema.medications.name,

          quantity: schema.doseEvents.quantity,
          status: schema.doseEvents.status,
          takenAt: schema.doseEvents.takenAt,

        .where(and(eq(schema.doseEvents.recipientId, c.get('recipientId')), gte(schema.doseEvents.scheduledAt, start), lt(schema.doseEvents.scheduledAt, end)))

      return c.json({ doses: rows });
```

`packages/shared/src/doses.ts`:
```ts
import { DateTime } from 'luxon';

type Input = {
  daysOfWeek: number[];
  timeOfDay: string; // HH:MM
  timeZone: string;
  startDate: string;
  endDate?: string | null;
  from: Date;
  to: Date;
};

function resolveLocal(day: DateTime, hour: number, minute: number): DateTime {
  const dt = day.set({ hour, minute, second: 0, millisecond: 0 }); // gap: luxon shifts forward
  const earlier = dt.minus({ hours: 1 });
  // Overlap: if one hour earlier shows the same wall-clock time, take the first occurrence.
  return earlier.hour === dt.hour && earlier.minute === dt.minute ? earlier : dt;
}

export function doseTimesBetween(o: Input): Date[] {
  const [h, m] = o.timeOfDay.split(':').map(Number) as [number, number];
  const out: Date[] = [];
  const last = DateTime.fromJSDate(o.to, { zone: o.timeZone }).startOf('day').plus({ days: 1 });
  for (let day = DateTime.fromJSDate(o.from, { zone: o.timeZone }).startOf('day').minus({ days: 1 }); day <= last; day = day.plus({ days: 1 })) {
    const iso = day.toISODate()!;
    if (iso < o.startDate || (o.endDate && iso > o.endDate)) continue;
    if (!o.daysOfWeek.includes(day.weekday)) continue;
    const t = resolveLocal(day, h, m);
    if (t.toMillis() >= o.from.getTime() && t.toMillis() < o.to.getTime()) out.push(t.toJSDate());
  }
  return out;
}
```

```ts
import { eq } from 'drizzle-orm';
import { schema, type Db } from '@dosecare/db';
import { doseTimesBetween } from '@dosecare/shared';

export async function materializeDoses(
  db: Db,
  now: Date,
  opts: { lookbackMinutes?: number; horizonHours?: number } = {},
): Promise<number> {
  const from = new Date(now.getTime() - (opts.lookbackMinutes ?? 60) * 60_000);
  const to = new Date(now.getTime() + (opts.horizonHours ?? 48) * 3_600_000);
  const rows = await db
    .select({
      scheduleId: schema.schedules.id,
      medicationId: schema.medications.id,
      recipientId: schema.medications.recipientId,
      daysOfWeek: schema.schedules.daysOfWeek,
      timeOfDay: schema.schedules.timeOfDay,
      quantity: schema.schedules.quantityPerDose,
      startDate: schema.schedules.startDate,
      endDate: schema.schedules.endDate,
      timeZone: schema.recipients.timeZone,
    })
    .from(schema.schedules)
    .innerJoin(schema.medications, eq(schema.medications.id, schema.schedules.medicationId))
    .innerJoin(schema.recipients, eq(schema.recipients.id, schema.medications.recipientId))
    .where(eq(schema.medications.active, true));

  const values = rows.flatMap((r) =>
    doseTimesBetween({
      daysOfWeek: r.daysOfWeek,
      timeOfDay: r.timeOfDay.slice(0, 5),
      timeZone: r.timeZone,
      startDate: r.startDate,
      endDate: r.endDate,
      from,
      to,
    }).map((scheduledAt) => ({
      scheduleId: r.scheduleId,
      medicationId: r.medicationId,
      recipientId: r.recipientId,
      scheduledAt,
      quantity: r.quantity,
    })),
  );

  let inserted = 0;
  for (let i = 0; i < values.length; i += 500) {
    const res = await db
      .insert(schema.doseEvents)
      .values(values.slice(i, i + 500))
      .onConflictDoNothing()
      .returning({ id: schema.doseEvents.id });
    inserted += res.length;
  }
  return inserted;
}
```

```ts
import { sql } from 'drizzle-orm';
import type { Db } from '@dosecare/db';

const count = (res: { rows: unknown[] }) => res.rows.length;

export async function enqueueReminders(db: Db, now: Date, opts: { staleMinutes?: number } = {}) {
  const stale = opts.staleMinutes ?? 30;
  return count(
    await db.execute(sql`
      insert into notification_outbox (kind, user_id, to_email, payload, dedupe_key, next_attempt_at)
      select 'reminder', u.id, u.email,
        jsonb_build_object('doseEventId', d.id, 'medication', m.name, 'strength', m.strength, 'unit', m.unit,
          'quantity', d.quantity, 'recipientName', r.display_name, 'scheduledAt', d.scheduled_at, 'timeZone', r.time_zone),
        'reminder:' || d.id || ':' || u.id, ${now}::timestamptz
      from dose_events d
      join medications m on m.id = d.medication_id
      join recipients r on r.id = d.recipient_id
      join notification_preferences p on p.recipient_id = d.recipient_id and p.reminders_enabled
      join users u on u.id = p.user_id
      where d.status = 'pending'
        and d.scheduled_at <= ${now}::timestamptz
        and d.scheduled_at > ${now}::timestamptz - make_interval(mins => ${stale})
      on conflict (dedupe_key) do nothing
      returning id`),
  );
}

export async function enqueueMissedAlerts(db: Db, now: Date) {
  return count(
    await db.execute(sql`
      insert into notification_outbox (kind, user_id, to_email, payload, dedupe_key, next_attempt_at)
      select 'missed_alert', u.id, u.email,
        jsonb_build_object('doseEventId', d.id, 'medication', m.name, 'strength', m.strength, 'unit', m.unit,
          'quantity', d.quantity, 'recipientName', r.display_name, 'scheduledAt', d.scheduled_at, 'timeZone', r.time_zone,
          'delayMinutes', p.missed_alert_delay_minutes),
        'missed:' || d.id || ':' || u.id, ${now}::timestamptz
      from dose_events d
      join medications m on m.id = d.medication_id
      join recipients r on r.id = d.recipient_id
      join notification_preferences p on p.recipient_id = d.recipient_id and p.missed_alert_enabled
      join users u on u.id = p.user_id
      where d.status in ('pending', 'missed')
        and d.scheduled_at > ${now}::timestamptz - interval '24 hours'
        and d.scheduled_at + make_interval(mins => p.missed_alert_delay_minutes) <= ${now}::timestamptz
      on conflict (dedupe_key) do nothing
      returning id`),
  );
}

export async function markMissed(db: Db, now: Date, graceMinutes = 120) {
  return count(
    await db.execute(sql`
      update dose_events set status = 'missed'
      where status = 'pending' and scheduled_at + make_interval(mins => ${graceMinutes}) <= ${now}::timestamptz
      returning id`),
  );
}

export async function enqueueLowStock(db: Db, now: Date, thresholdDays = 7) {
  return count(
    await db.execute(sql`
      with stock as (
        select m.id as medication_id, m.name, m.recipient_id,
          coalesce(sum(sm.quantity), 0)::float8 as remaining,
          max(sm.created_at) filter (where sm.reason = 'refill') as last_refill
        from medications m
        join stock_movements sm on sm.medication_id = m.id
        where m.active
        group by m.id
        having bool_or(sm.reason <> 'dose')
      ), daily as (
        select sc.medication_id, sum(sc.quantity_per_dose * cardinality(sc.days_of_week) / 7.0)::float8 as per_day
        from schedules sc
        join medications m on m.id = sc.medication_id
        join recipients r on r.id = m.recipient_id
        where sc.end_date is null or sc.end_date >= (${now}::timestamptz at time zone r.time_zone)::date
        group by sc.medication_id
      )
      insert into notification_outbox (kind, user_id, to_email, payload, dedupe_key, next_attempt_at)
      select 'low_stock', u.id, u.email,
        jsonb_build_object('medication', s.name, 'recipientName', r.display_name,
          'daysLeft', round((s.remaining / d.per_day)::numeric, 1), 'remaining', s.remaining),
        'low_stock:' || s.medication_id || ':' || coalesce(extract(epoch from s.last_refill)::bigint::text, '0') || ':' || u.id,
        ${now}::timestamptz
      from stock s
      join daily d on d.medication_id = s.medication_id
      join recipients r on r.id = s.recipient_id
      join recipient_members rm on rm.recipient_id = s.recipient_id and rm.role in ('owner', 'editor')
      join users u on u.id = rm.user_id
      where d.per_day > 0 and s.remaining / d.per_day <= ${thresholdDays}
      on conflict (dedupe_key) do nothing
      returning id`),
  );
}
```

```ts
export type Kind = 'reminder' | 'missed_alert' | 'low_stock' | 'invitation';

const DISCLAIMER = 'DoseCare is a tracking tool and does not provide medical advice.';
const esc = (s: unknown) =>
  String(s).replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
const time = (iso: string, tz: string) =>
  new Intl.DateTimeFormat('en-GB', { timeZone: tz, hour: '2-digit', minute: '2-digit', hourCycle: 'h23' }).format(new Date(iso));
const dosage = (p: Payload) => `${p.quantity} ${p.unit}${p.strength ? ` (${p.strength})` : ''}`;

function build(subject: string, lines: string[]) {
  const text = [...lines, '', DISCLAIMER].join('\n');
  const html = `<div style="font-family:sans-serif">${lines.map((l) => `<p>${esc(l)}</p>`).join('')}<hr><p style="color:#666;font-size:12px">${esc(DISCLAIMER)}</p></div>`;
  return { subject, text, html };
}

export function renderEmail(kind: Kind, p: Payload) {
  switch (kind) {
    case 'reminder': {
      const at = time(p.scheduledAt, p.timeZone);
      return build(`Time for ${p.recipientName} to take ${p.medication} at ${at}`, [
        `${p.recipientName} is due to take ${p.medication} at ${at}.`,
        `Dose: ${dosage(p)}.`,
      ]);
    }
    case 'missed_alert': {
      const at = time(p.scheduledAt, p.timeZone);
      return build(`Missed dose: ${p.medication} for ${p.recipientName} (due ${at})`, [
        `The ${at} dose of ${p.medication} for ${p.recipientName} has not been recorded ${p.delayMinutes} minutes after it was due.`,
      ]);
    }
    case 'low_stock':
      return build(`Low stock: ${p.medication} for ${p.recipientName} (about ${p.daysLeft} days left)`, [
        `${p.medication} for ${p.recipientName} is running low: ${p.remaining} left, about ${p.daysLeft} days at the current schedule.`,
      ]);
    case 'invitation':
      return build(`${p.inviterName} invited you to help with ${p.recipientName}'s medication`, [
        `${p.inviterName} invited you to follow ${p.recipientName}'s medication as ${p.role}.`,
        `Accept the invitation: ${p.link}`,
      ]);
  }
```

`apps/worker/src/dispatch.ts`:
```ts
import { sql } from 'drizzle-orm';
import type { Db } from '@dosecare/db';
import type { Clock } from '@dosecare/shared';
import type { Mailer } from './mailer';
import { renderEmail, type Kind } from './render';

type Row = { id: string; kind: Kind; to_email: string; payload: Record<string, unknown>; dedupe_key: string; attempts: number };

export async function dispatch(
  db: Db,
  deps: { mailer: Mailer; clock: Clock; random?: () => number },
  opts: { batchSize?: number; visibilityMs?: number; maxAttempts?: number } = {},
) {
  const { batchSize = 20, visibilityMs = 60_000, maxAttempts = 5 } = opts;
  const random = deps.random ?? Math.random;
  const now = deps.clock.now();
  const lockedUntil = new Date(now.getTime() + visibilityMs);

  const claimed = await db.execute(sql`
    with c as (
      select id from notification_outbox
      where (status = 'pending' and next_attempt_at <= ${now}::timestamptz)
         or (status = 'sending' and locked_until <= ${now}::timestamptz)
      order by next_attempt_at
      limit ${batchSize}
      for update skip locked
    )
    update notification_outbox o
    set status = 'sending', locked_until = ${lockedUntil}::timestamptz, attempts = o.attempts + 1
    from c where o.id = c.id
    returning o.id, o.kind, o.to_email, o.payload, o.dedupe_key, o.attempts`);

  const result = { sent: 0, retried: 0, failed: 0 };
  for (const row of claimed.rows as Row[]) {
    try {
      const email = renderEmail(row.kind, row.payload);
      await deps.mailer.send({ to: row.to_email, messageId: row.dedupe_key, ...email });
      await db.execute(sql`
        update notification_outbox
        set status = 'sent', sent_at = ${now}::timestamptz, locked_until = null, last_error = null, payload = payload - 'token'
        where id = ${row.id}`);
      result.sent++;
    } catch (err) {
      const message = err instanceof Error ? err.message : String(err);
      if (row.attempts >= maxAttempts) {
        await db.execute(sql`update notification_outbox set status = 'failed', locked_until = null, last_error = ${message} where id = ${row.id}`);
        result.failed++;
      } else {
        const base = Math.min(30_000 * 2 ** (row.attempts - 1), 3_600_000);
        const next = new Date(now.getTime() + base * (0.8 + 0.4 * random()));
        await db.execute(sql`
          update notification_outbox
          set status = 'pending', locked_until = null, last_error = ${message}, next_attempt_at = ${next}::timestamptz
          where id = ${row.id}`);
        result.retried++;
      }
    }
  }
  return result;
}
```

```ts
import { runCycle } from './cycle';
import { SmtpMailer } from './mailer';

const url = process.env.DATABASE_URL;
if (!url) throw new Error('DATABASE_URL is required');
const { db, pool } = createDb(url);
const mailer = new SmtpMailer({
  host: process.env.SMTP_HOST ?? 'localhost',
  port: Number(process.env.SMTP_PORT ?? 1026),
  from: process.env.MAIL_FROM ?? 'DoseCare <no-reply@dosecare.local>',
});
const clock = new SystemClock();
const everyMs = Number(process.env.CYCLE_SECONDS ?? 30) * 1000;

let stopping = false;
let timer: NodeJS.Timeout | undefined;

async function tick() {
  try {
    const r = await runCycle(db, { mailer, clock });
    console.log(`[worker] ${clock.now().toISOString()} ${JSON.stringify(r)}`);
  } catch (err) {
    console.error('[worker] cycle failed', err);
  }
  if (!stopping) timer = setTimeout(tick, everyMs);
  else await pool.end();
}

for (const sig of ['SIGTERM', 'SIGINT'] as const) {
  process.on(sig, () => {
    stopping = true;
    if (timer) {
      clearTimeout(timer);
      void pool.end().then(() => process.exit(0));
    }
  });
}
void tick();
```

```ts
export const api = hc<AppType>('/api');

export class ApiRequestError extends Error {
  override name = 'ApiRequestError';
  constructor(public status: number, public code: string, message: string) {
    super(message);
  }
}

export async function unwrap<T>(res: Response): Promise<T> {
  if (res.status === 204) return undefined as T;
  const body = (await res.json().catch(() => null)) as { error?: { code?: string; message?: string } } | null;
  if (!res.ok) throw new ApiRequestError(res.status, body?.error?.code ?? 'unknown', body?.error?.message ?? res.statusText ?? 'Request failed');
  return body as T;
}
```

```ts
import { localDate } from '@dosecare/shared';

export type Role = 'owner' | 'editor' | 'viewer';
export type DoseStatus = 'pending' | 'taken' | 'skipped' | 'missed';

export const canRecord = (role: Role) => role === 'owner' || role === 'editor';

const META: Record<DoseStatus, { label: string; color: 'default' | 'success' | 'warning' | 'error' }> = {
  pending: { label: 'Pending', color: 'default' },
  taken: { label: 'Taken', color: 'success' },
  skipped: { label: 'Skipped', color: 'warning' },
  missed: { label: 'Missed', color: 'error' },
};
export const statusMeta = (s: DoseStatus) => META[s];

export const formatLocalTime = (iso: string, timeZone: string) =>
  new Intl.DateTimeFormat('en-GB', { timeZone, hour: '2-digit', minute: '2-digit', hourCycle: 'h23' }).format(new Date(iso));

export function todayRange(now: Date, timeZone: string) {
  const d = localDate(now, timeZone);
  return { from: d, to: d };
}
```

```tsx
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { App, Button, Card, Empty, List, Tag } from 'antd';
import Link from 'next/link';
import { api, unwrap } from '@/lib/api';
import { canRecord, formatLocalTime, statusMeta, todayRange, type DoseStatus, type Role } from '@/lib/dose';

export type PersonSummary = { id: string; displayName: string; timeZone: string; role: Role };
type Dose = { id: string; medicationName: string; scheduledAt: string; quantity: number; status: DoseStatus };

export function PersonToday({ person }: { person: PersonSummary }) {
  const qc = useQueryClient();
  const { message } = App.useApp();
  const range = todayRange(new Date(), person.timeZone);
  const key = ['doses', person.id, range.from];
  const doses = useQuery({
    queryKey: key,
    refetchInterval: 30_000,
    queryFn: async () =>
      unwrap<{ doses: Dose[] }>(await api.recipients[':id'].doses.$get({ param: { id: person.id }, query: range })),
  });
  const record = useMutation({
    mutationFn: async ({ id, action }: { id: string; action: 'take' | 'skip' }) =>
      unwrap(await api.doses[':id'][action].$post({ param: { id } })),
    onSuccess: () => qc.invalidateQueries({ queryKey: ['doses', person.id] }),
    onError: (e) => message.error(e.message),
  });

  return (
    <Card
      className="mb-4"
      title={<Link href={`/people/${person.id}`}>{person.displayName}</Link>}
      extra={<span className="text-gray-500">{person.timeZone}</span>}
      loading={doses.isLoading}
    >
      {doses.data && doses.data.doses.length === 0 ? (
        <Empty description="No doses today. Doses appear within a minute after you add a schedule." />
      ) : (
        <List
          dataSource={doses.data?.doses ?? []}
          renderItem={(d) => {
            const meta = statusMeta(d.status);
            const open = d.status === 'pending' || d.status === 'missed';
            return (
              <List.Item

                          Skip
                        </Button>,
                      ]
                    : []
                }
              >
                <List.Item.Meta title={`${formatLocalTime(d.scheduledAt, person.timeZone)} · ${d.medicationName}`} description={`${d.quantity} per dose`} />
                <Tag color={meta.color}>{meta.label}</Tag>
              </List.Item>
            );
```

```ts
const DAY = ['', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'];

export function scheduleSummary(s: { daysOfWeek: number[]; timeOfDay: string; quantityPerDose: number }) {
  const days = [...s.daysOfWeek].sort((a, b) => a - b);
  const when = days.length === 7 ? 'Every day' : days.map((d) => DAY[d]).join(', ');
  const qty = s.quantityPerDose === 1 ? '' : ` · ${s.quantityPerDose} per dose`;
  return `${when} at ${s.timeOfDay.slice(0, 5)}${qty}`;
}

export function stockLabel(s: { tracked: boolean; remaining: number; daysLeft: number | null }) {
  if (!s.tracked) return { text: 'Stock not tracked', color: 'default' as const };
  if (s.daysLeft === null) return { text: `${s.remaining} left`, color: 'default' as const };
  const color = s.daysLeft <= 3 ? ('error' as const) : s.daysLeft <= 7 ? ('warning' as const) : ('success' as const);
  return { text: `${s.remaining} left · about ${Math.max(0, Math.floor(s.daysLeft))} days`, color };
}
```

`apps/api/src/seed.ts`:
```ts
import { eq } from 'drizzle-orm';
import { schema, type Db } from '@dosecare/db';
import { doseTimesBetween, type Clock } from '@dosecare/shared';
import { hashPassword } from './auth/password';
import { addMember, createRecipient } from './services/recipients';

const TZ = 'Europe/Paris';
const ALL_DAYS = [1, 2, 3, 4, 5, 6, 7];

export async function seedDemo(db: Db, clock: Clock): Promise<{ created: boolean }> {
  const [existing] = await db.select({ id: schema.users.id }).from(schema.users).where(eq(schema.users.email, 'demo@dosecare.local'));
  if (existing) return { created: false };

  const now = clock.now();
  const passwordHash = await hashPassword('demo-password-123');
  const [demo] = await db.insert(schema.users).values({ email: 'demo@dosecare.local', passwordHash, name: 'Demo User' }).returning();
  const [sam] = await db.insert(schema.users).values({ email: 'sam@dosecare.local', passwordHash, name: 'Sam Carer' }).returning();

  await createRecipient(db, { ownerId: demo!.id, displayName: 'Demo User', timeZone: TZ });
  const rose = await createRecipient(db, { ownerId: demo!.id, displayName: 'Grandma Rose', timeZone: TZ });
  await addMember(db, { recipientId: rose.id, userId: sam!.id, role: 'editor' });
  const leo = await createRecipient(db, { ownerId: sam!.id, displayName: 'Leo', timeZone: TZ });
  await addMember(db, { recipientId: leo.id, userId: demo!.id, role: 'viewer' });

  const startDate = new Date(now.getTime() - 30 * 86_400_000).toISOString().slice(0, 10);
  const addMed = async (recipientId: string, name: string, strength: string | null, unit: string, times: string[], refill: number) => {
    const [m] = await db.insert(schema.medications).values({ recipientId, name, strength, unit }).returning();
    const scheds = [];
    for (const timeOfDay of times) {
      const [s] = await db.insert(schema.schedules).values({ medicationId: m!.id, daysOfWeek: ALL_DAYS, timeOfDay, quantityPerDose: 1, startDate }).returning();
      scheds.push(s!);
    }
    await db.insert(schema.stockMovements).values({ medicationId: m!.id, quantity: refill, reason: 'refill', createdAt: new Date(now.getTime() - 5 * 86_400_000) });
    return { med: m!, scheds };
  };

  const metformin = await addMed(rose.id, 'Metformin', '500', 'mg', ['08:00', '20:00'], 60);
  await addMed(rose.id, 'Lisinopril', '10', 'mg', ['09:00'], 30);
  await addMed(rose.id, 'Vitamin D', '1000', 'IU', ['12:00'], 6);
  await addMed(leo.id, 'Allergy syrup', '5', 'ml', ['19:00'], 20);

  // Seven days of history for Metformin: mostly taken, one skipped, one missed.
  const from = new Date(now.getTime() - 7 * 86_400_000);
  const rows = metformin.scheds.flatMap((s) =>
    doseTimesBetween({ daysOfWeek: ALL_DAYS, timeOfDay: s.timeOfDay.slice(0, 5), timeZone: TZ, startDate, from, to: new Date(now.getTime() - 3 * 3_600_000) }).map((scheduledAt) => ({
      scheduleId: s.id, medicationId: metformin.med.id, recipientId: rose.id, scheduledAt, quantity: 1, status: 'taken' as const,
      takenAt: new Date(scheduledAt.getTime() + 10 * 60_000), recordedBy: demo!.id,
    })),
  );
  rows.sort((a, b) => a.scheduledAt.getTime() - b.scheduledAt.getTime());
  if (rows.length >= 4) {
    rows[2] = { ...rows[2]!, status: 'skipped' as never, takenAt: null as never };
    rows[3] = { ...rows[3]!, status: 'missed' as never, takenAt: null as never, recordedBy: null as never };
  }
  await db.insert(schema.doseEvents).values(rows);
  return { created: true };
}
```

- [ ] **Step 2: ADRs**

`docs/adr/0001-own-sessions.md`:
```markdown
# 0001. Server-side sessions implemented in the API

Status: accepted

Context: web today, mobile later. Needs revocation, no third-party service, small attack surface.

Decision: opaque random 32-byte tokens, only the SHA-256 hash stored in `sessions`, argon2id password hashes, `httpOnly` `SameSite=Lax` cookie, `Authorization: Bearer` accepted for mobile. Next.js proxies `/api/*` so web and API share an origin.

Consequences: logout and expiry are enforced in the database, and a leaked database does not leak usable tokens. We own security-sensitive code, so it is small and covered by tests (expiry, revocation, timing-equal login errors, rate limiting). No email verification or password reset in v1.
```
`docs/adr/0002-postgres-outbox.md`:
```markdown
# 0002. Postgres outbox as the job queue

Status: accepted

Context: reminders, missed-dose alerts, low-stock alerts and invitation emails must be sent reliably, with no extra infrastructure.

Decision: a `notification_outbox` table with a unique `dedupe_key`. Enqueueing is set-based SQL (`INSERT ... SELECT ... ON CONFLICT DO NOTHING`), so running a cycle twice is harmless. Dispatch claims rows with `FOR UPDATE SKIP LOCKED` in one statement, so several workers can run together.

Consequences: no broker to operate and everything is testable on a real database. Throughput is bounded by Postgres, which is ample here. A dedicated queue would only be needed at much higher volume.
```
`docs/adr/0003-at-least-once-delivery.md`:
```markdown
# 0003. At-least-once email delivery

Status: accepted

Context: the worker can crash between sending an email and recording `sent`.

Decision: rows are claimed with a visibility timeout (`locked_until`) and reclaimed after a crash. Failures retry with exponential backoff and jitter, then become `failed`. The `dedupe_key` is used as the email `Message-ID` so downstream systems can drop duplicates.

Consequences: in that rare crash window an email can be delivered twice. Exactly-once delivery over SMTP is not achievable, so the system is explicit about at-least-once and prevents duplicates at enqueue time.
```
`docs/adr/0004-stock-ledger.md`:
```markdown
# 0004. Stock as a movement ledger

Status: accepted

Context: remaining quantity of a medication must stay correct when doses are taken, refills happen and corrections are made.

Decision: `stock_movements` (`refill`, `dose`, `adjustment`) with signed quantities; remaining stock is the sum. A taken dose writes its movement in the same transaction as the status change, and only when stock is tracked (a refill or adjustment exists), so people who never track stock get no alerts.

Consequences: full audit trail and no counter that can drift. Reads aggregate movements, which is cheap at this scale. Low-stock alerts are deduplicated per refill cycle.
```
